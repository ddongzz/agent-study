### 1. 핵심 내용 5줄 요약
1. 고도화된 AI 서비스는 파인튜닝, RAG, 멀티툴 오케스트레이션, 메모리를 함께 쓰는 에이전트 중심 구조로 진화하고 있다.
2. 모델 증류는 큰 모델(teacher)의 성능을 유지하며 작은 모델(student)로 옮겨 담는 압축 기술이다.
3. 증류 과정에서 student 모델은 teacher가 출력하는 확률 분포(soft target)를 학습하여 판단 방식을 따라 하게 된다.
4. 증류는 모바일/엣지 환경, 온디바이스 구동, 사내 비공개 시스템 배포 등 자원이 제한된 상황에서 유용하다.
5. 주요 모델 최적화 방식은 프롬프팅(입력 설계), 파인튜닝(파라미터 재학습), RAG(외부 검색 결합), 증류(Teacher-Student 전이 학습)로 나뉜다.

### 2. 객관식 퀴즈 3문제

**[문제 1]**
모델 증류(Model Distillation)의 대표적인 구조는 무엇인가요?
① 인코더-디코더 구조  
② Teacher-Student 구조  
③ 제너레이터-디스크리미네이터 구조  
④ 입력-출력 매핑 구조  

* **정답:** ②
* **근거가 된 노트 문장:** "대표 구조는 teacher-student 구조."

---

**[문제 2]**
모델 증류가 특히 유용한 상황으로 볼 수 **없는** 것은 무엇인가요?
① 모바일이나 엣지처럼 컴퓨팅 자원이 제한된 환경  
② 큰 모델을 API 호출 없이 기기 안(온디바이스)에서 돌리고 싶을 때  
③ 사내 비공개 시스템에 모델을 직접 배포해야 할 때  
④ 일반 지도학습만 사용하여 정답 라벨만을 학습시킬 때  

* **정답:** ④
* **근거가 된 노트 문장:** "증류가 특히 유용한 상황 - 모바일이나 엣지처럼 컴퓨팅 자원이 제한된 환경 - 큰 모델을 API 호출 없이 기기 안(온디바이스)에서 돌리고 싶을 때 - 사내 비공개 시스템에 모델을 직접 배포해야 할 때" (노트에 일반 지도학습만 사용하는 상황은 유용한 상황으로 적혀 있지 않음)

노트에 제시된 모델 최적화 방식 중 '지식을 보강'하고 '외부 검색을 결합'하는 방식은 무엇인가요?
① 프롬프팅  
② 파인튜닝  
③ RAG  
④ 증류  

* **정답:** ③
* **근거가 된 노트 문장:** "- RAG: 지식을 보강. 외부 검색을 결합. 최신 정보 반영, 출처 기반 응답."
